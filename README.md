# 单位换算器（Homework1）

一个可以本地直接打开的小网页：在长度、质量、温度、体积、时间和数据量之间换算。

## 范围

- 纯前端，无后端、无登录、无网络请求
- 不接入真实用户数据，也不处理密钥或生产环境配置
- 换算系数写在 `app.js` 里，仅供课堂演示

## 如何运行

用浏览器打开 `index.html` 即可，例如：

```powershell
start index.html
```

或在当前目录启动一个静态服务后再访问：

```powershell
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 功能

- 切换类别（长度 / 质量 / 温度 / 体积 / 时间 / 数据量）
- 输入数值并选择单位，即时显示结果
- 一键交换“从 / 到”单位
- 查看当前输入对应的常用对照表
