# CampusClaw

CampusClaw 是按班级隔离的课程知识库和解题助手。教师把本班材料上传入库，并配置智能体、技能和外部工具；学生只对着本班内容连续提问。回答以 SSE 逐段返回，命中材料时在回答框里标出出处，需要时再调用教师登记的 MCP 工具。

班级边界和角色权限都在服务端判定。检索用的班级只从登录会话读取，不采用请求体里自填的 `class_id`。完整的架构、接口、数据模型和运维说明见 [docs/project.md](docs/project.md)。

## 能做什么

学生可以登录、按标题查看本班材料，并在 `/ask` 里选择已启用的智能体连续追问。页面会显示这个智能体已启用的技能。对话还没有消息时可以更换智能体，换的是当前这一条会话；一旦发出过消息就不能再换。学生不能改提示词、技能、智能体或 MCP 服务器。

教师在此之上可以上传、编辑、删除本班材料（仅 `.txt` / `.md`），并按 `auto`、`custom`、`hierarchy` 重新切片。管理页 `/admin` 有三个页签：

- **智能体**：名称、角色提示词、绑定的技能和材料、启用开关。
- **技能**：名称、适用条件、资料学科、工具和正文。班内名称唯一。
- **MCP**：登记服务器、连接并发现工具、查看说明和最近调用。令牌只写不读，接口不把原文送回浏览器。

材料页上教师可以切换班级查看；解题助手的检索和回答仍以会话所在班级为准。

## 一次提问怎么回答

服务端按下面的顺序处理一条消息：

1. 取会话和已绑定的智能体，确认属于当前用户的班级。
2. 在该智能体已启用的技能里按适用条件打分，最多选中一个。没有匹配时不把任何技能正文发给模型，也不声明外部工具。
3. 只在这个智能体绑定的材料里检索，最多取 4 条，再按技能上的学科过滤。
4. 把角色提示词和选中技能写入系统消息，把命中的资料和问题写入用户消息，然后逐段生成。
5. 若选中技能的工具是 `名字@服务器`，模型可以发起调用。宿主校验参数、用服务端令牌访问 MCP，再把结果作为工具消息送回模型。`knowledge_search` 不走 MCP。

参考资料显示在回答框内，只有序号和材料标题。没有命中时仍然作答，只是不标编号。工具调用显示在正文之前，例如「本次用到：weather_query@campus-tools（成功）」。自带的 `mcp-demo` 提供 `formula_hint`（公式提示）、`unit_convert`（单位换算）和 `weather_query`（按城市查当前天气）。

名称里含「解题引导」的技能会附加一条硬性要求：先判断对错并指出错在哪一项，不写得数。

## 运行结构

浏览器只访问 `web`。Nginx 提供页面，并把 `/api/` 反代到 Go API；代理缓冲关闭，以便 SSE 逐段输出。MySQL、Qdrant 和 `mcp-demo` 只在 Compose 网络内，不映射到宿主机。对话和嵌入请求由 API 容器出网访问课程网关，密钥不会下发到浏览器。

| 服务 | 作用 |
| --- | --- |
| `web` | 静态页面与 `/api/` 反向代理，唯一映射宿主机端口 |
| `api` | 鉴权、材料入库、检索、技能路由、SSE 生成、MCP 编排 |
| `db` | 用户、材料、切片、会话、技能、审计 |
| `qdrant` | 向量索引 |
| `mcp-demo` | 自建 MCP 服务，监听内网 `8090` |

## 启动

需要 Docker Desktop（Compose v2）。在仓库根目录执行：

```powershell
.\start.ps1
```

没有 `.env` 时，脚本会从 `.env.example` 复制一份并停下来。填好 `SESSION_SECRET`、`DB_PASSWORD`、`MYSQL_ROOT_PASSWORD`、`SEED_PASSWORD` 后再运行。已有 `.env` 时，它执行 `docker compose up --build -d --wait`，并打印下面的地址。也可以直接：

```powershell
docker compose up -d --build
```

首次启动会建表、写入种子数据并等待 Qdrant，健康检查留了大约三分钟。默认入口（`WEB_PORT` 未改时）：

- 登录：http://localhost:8080/login
- 材料：http://localhost:8080/
- 解题助手：http://localhost:8080/ask
- 接口文档：http://localhost:8080/swagger/ （`/openapi.json` 与 `GET /health` 无需登录，健康检查不访问数据库）

对话和嵌入使用 `.env` 里的 `CHAT_*`、`EMBEDDING_*`。未配置对话密钥时不调用网关，由服务端根据命中材料在本地组织回答。向量维度以 `EMBEDDING_DIM` 为准，没有设置时才看 `VECTOR_SIZE`。改过 `.env` 后需要重新 `docker compose up -d`，新值才会进入容器。`SESSION_SECRET` 一变，已发出的令牌全部失效。

密钥只放在本机 `.env`，不要写入源码或提交到 Git。

## 预置账号

口令是 `.env` 里的 `SEED_PASSWORD`，库中只存 bcrypt。

| 用户名 | 角色 | 班级 |
| --- | --- | --- |
| `teacher_a` | 教师 | A 班 |
| `student_a1` | 学生 | A 班 |
| `student_b1` | 学生 | B 班 |

种子数据还有两个班各一份标题可区分的数学材料、一条默认角色提示词，以及一个「默认解题助手」。绑定在助手上的技能是「数学解题引导」（工具 `knowledge_search`）和「天气查询」（工具 `weather_query@campus-tools`）。

学生按编号打开其他班的材料会得到 **404**。用其他班的条件检索得到的是 **200 和空结果**，而不是另一班的材料。
